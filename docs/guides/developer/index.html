Developer guides

Plain-language guides to the principles. They cover everything, including what experienced developers already know.

Each guide explains its terms as it goes, says why an idea matters, and links to the original source, so you can read any of them without having met the names before.

  1. Developer Guide: a field guide to the named principles and methodologies you will meet in real software work, from the Zen of Python to Conway's Law, each with a short explanation and a canonical link.
  2. Principles for Building Quality Software and Apps: a working map of the core design, testing and operability principles (KISS, YAGNI, DRY, SOLID, the test pyramid, the twelve-factor app), where they pull against each other, and how to use them with AI coding agents.
  3. Using the agents and commands: how to run the loop in this repo, from giving the coordinator a brief to approving what the Learn loop proposes.
  4. Testing the skills: how the 103 skills are tried out on three small test apps and scored keep, merge or drop.

The guides link to the rest of the site: the learning path, all principles, the skills, the agents and the sources.
