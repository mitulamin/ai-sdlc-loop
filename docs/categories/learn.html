Stage 9: Learn

Turn what went wrong into a better loop.

The loop gets better only if mistakes change the rules. This closes the cycle and feeds back into stage one of the next project.

The 11 skills here run in these phases: Learn (11). See them in run order.

11 principles

  1. 9.1
    When the reviewer missed a mistake, give the reviewer a new rule; if the mistake is mechanical, build a lint, hook or CI check instead

    Skill reviewer-rule-or-mechanical-check · Learn phase · run slot 33 · All three runs (harness and Learn) Clean

  2. 9.2
    Enforce standards at review, not by loading them into the implementer's context

    Skill enforce-standards-at-review · Learn phase · run slot 34 · All three runs (harness and Learn) Clean

  3. 9.3
    Remove or clarify rules that don't change behaviour

    Skill prune-rules-that-dont-change-behaviour · Learn phase · run slot 35 · All three runs (harness and Learn) Clean

  4. 9.5
    Ask what conditions allowed the failure, not who caused it (blameless, 5 whys)

    Skill blameless-five-whys · Learn phase · run slot 36 · All three runs (harness and Learn) Clean

  5. 9.6
    Group failures by the mechanism behind them, not by error text

    Skill group-failures-by-mechanism · Learn phase · run slot 37 · All three runs (harness and Learn) Clean

  6. 9.7
    Before hardening a skill, reproduce the failure as a baseline scenario and record the agent's excuses; then close the loophole and re-test

    Skill tdd-for-skills · Learn phase · run slot 38 · All three runs (harness and Learn) Clean

  7. 9.8
    Keep each learned edit small, to one surface, and keep behaviour that already passes

    Skill small-one-surface-edits · Learn phase · run slot 39 · All three runs (harness and Learn) Clean

  8. 9.9
    Accept a rule change coming out of a retrospective only if it measurably improves results on held-out cases it was not tuned on

    Skill held-out-acceptance · Learn phase · run slot 40 · All three runs (harness and Learn) Rewritten

  9. 9.10
    A human approves each learned change before it goes live

    Skill human-approves-learned-changes · Learn phase · run slot 41 · All three runs (harness and Learn) Clean

  10. 9.11
    Capture corrections as they happen; process them later in a batch

    Skill capture-corrections-batch-later · Learn phase · run slot 42 · All three runs (harness and Learn) Clean

  11. 9.12
    Keep a record of every accepted and rejected edit

    Skill ledger-of-edits · Learn phase · run slot 43 · All three runs (harness and Learn) Clean
