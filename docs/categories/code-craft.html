Stage 3: Code craft

Write the smallest change that does the job, in the style already there.

This is the day-to-day work of building. The theme is restraint: no speculative code, no drive-by edits.

The 14 skills here run in these phases: Build (14). See them in run order.

14 principles

  1. 3.1
    When you write code, write the minimum that solves the stated problem, with no speculative features, options or hooks

    Skill minimum-code · Build phase · run slot 19 · App A: CLI tool, greenfield Rewritten

  2. 3.2
    Make surgical changes: every changed line traces to the request

    Skill surgical-changes · Build phase · run slot 93 · App C: Brownfield fix and refactor Rewritten

  3. 3.3
    Match the existing style and conventions

    Skill match-existing-conventions · Build phase · run slot 94 · App C: Brownfield fix and refactor Rewritten

  4. 3.4
    Keep functions small and at one level of abstraction

    Separate commands from queries; no hidden side effects
