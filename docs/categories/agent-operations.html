Stage 8: Agent operations

Run the agents themselves well.

Context is limited and expensive. This stage is about what an agent sees, how skills are loaded, and how work is split between a coordinator and the agents it starts.

10 principles

  1. 8.1 Load only the context the task needs, such as the relevant spec section
  2. 8.2 Keep one short always-on rules file: stack, commands, conventions, boundaries
  3. 8.3 Progressive disclosure: short description always, body on trigger, references on demand
  4. 8.4 The skill description is the trigger; put the 'when to use' there
  5. 8.5 Test skills with evals before trusting them
  6. 8.6 Summarise progress when the context gets long
  7. 8.7 Use fresh-context subagents for fact-finding and review
  8. 8.8 Write reports to files, not into the chat
  9. 8.9 Answer first, cut ceremony, keep code and errors verbatim
  10. 8.10 Don't fight the harness: detect existing isolation and use native tools first
