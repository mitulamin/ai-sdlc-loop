Stage 5: Debug and observe

When something breaks, find the cause before you change anything.

Debugging is a method, not a hunch. Build a fast feedback loop, reproduce, narrow down, fix, then guard against it coming back.

The 14 skills here run in these phases: Build (1), Debug (11), Secure (1), Review & ship (1). See them in run order.

General principles 5 principles

  1. 5.1
    No fixes without root-cause investigation first: trace back to the original trigger, not where the symptom showed up.
