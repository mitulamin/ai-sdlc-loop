Stage 1: Plan and specify

Decide what you are building before any code exists.

Everything later depends on this. A vague ask turns into confident, wrong code, so this stage is about surfacing assumptions, asking questions and agreeing a spec.

The 8 skills here run in these phases: Plan (8). See them in run order.

8 principles

  1. 1.1
    State assumptions; when something is unclear, stop and ask rather than pick silently

    Skill surface-assumptions · Plan phase · run slot 11 · App A: CLI tool, greenfield Rewritten

  2. 1.2
    Write a spec before code for non-trivial work, and gate each phase on human review

    Skill spec-before-code · Plan phase · run slot 44 · App B: Small CRUD web app with auth, greenfield Clean

  3. 1.3
    Break big asks into a capability map and build modules in dependency order

    Skill capability-map-and-dependency-order · Plan phase · run slot 45 · App B: Small CRUD web app with auth, greenfield Clean

  4. 1.4

  5. 1.5
    Look facts up yourself; only ask the human for decisions

    Skill look-up-facts-ask-for-decisions · Plan phase · run slot 13 · App A: CLI tool, greenfield Clean

  6. 1.6
