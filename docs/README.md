# docs

The static website (GitHub Pages): a landing page that explains the project, a learning path through the 103 principles, a page per category (with its subgroups and skills), a page per principle, a searchable and sortable table, a skills page with the run order and filters for phase, test app and licence status, an agents page with the agents and commands and the skills each loads, the list of source repos and the developer guide pages. Client-side JavaScript only, no build step to view it, no external scripts or trackers. Open `docs/index.html` in a browser to try it. The landing page is `index.html` and the learning path is `path.html`.

## Generated and hand-written

Everything is generated by `scripts/build-site.py` from `data/principles.json`, `data/sources.json`, `data/skill-principle-map.json`, `data/taxonomy.json`, `data/scorecard.json` and `guides/developer/*.md`. The agents page (`agents.html`) reuses the model in `scripts/build-agents.py`, so it also reads `skills/*/SKILL.md`. The only hand-written files are:

- `assets/style.css`
- `assets/site.js`
- `.nojekyll`
- this `README.md`

Do not edit generated files, they are overwritten. After changing anything in `data/` or `guides/developer/`, run:

```
scripts/build-site.py
```

CI runs `scripts/build-site.py --check` and fails if the output is stale. The landing page is built by `Site.landing_page` in the script. The learning-path text for each category lives in `PATH_TEXT` at the top of the script.

## Publishing

Settings, Pages, Source "Deploy from a branch", Branch `main`, folder `/docs`.
