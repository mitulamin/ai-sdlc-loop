The 19 agents and 7 commands

The human talks only to the coordinator. For each of the 9 phases it starts a producer and then a strictly adversarial reviewer, each in a fresh context. Producers load each skill's Do and Don't lists together. Reviewers load only each skill's adversarial reviewer checks and the Don't list. A phase loads the skills whose phase in data/skill-principle-map.json is that phase. The agent and command files are generated by scripts/build-agents.py.

Commands

The human gives a command to the coordinator, which runs the loop for each phase on its own and reports at the end of the cycle. The Harness phase has no command: the coordinator runs it.

Command Phases What it is for Skills
/planPlan
Turn the brief into a spec and a plan with verifiable goals.
8
/designDesign
Design the modules, contracts and decisions the plan needs.
18
/buildBuild
Implement the plan in small, safe steps that keep the build green.
15
/verifyVerify, Debug
Prove the build works with tests and evidence, and find the root cause of what fails.
19
/reviewSecure, Review & ship
Review the change for security and quality before it ships.
22
/shipReview & ship
Get the reviewed change merged and released through the gates.
13
/retroLearn
Turn the human's end-of-cycle feedback into proposed skill and check edits.
11
