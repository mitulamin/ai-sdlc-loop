# Licensing notes

- This repo's licence is in [LICENSE](LICENSE) (GNU GPL v3). Do not replace or edit that file without a deliberate decision recorded in [CHANGELOG.md](CHANGELOG.md).
- Content borrowed from other repos keeps its original licence. Each borrowed file is credited in the `SOURCES.md` next to the skill that uses it, with the source link pinned to a commit and the source's licence.
- The licence of each source repo is recorded in [data/sources.json](data/sources.json). It reads `TBD` until someone has checked it. Do not borrow from a repo whose licence is `TBD` or incompatible.
- Principles in `data/principles.json` are short statements written for this repo. They name their sources but do not reproduce them.
- If you use this repo as a starter, check how this licence applies to the project you create from `template/`.
