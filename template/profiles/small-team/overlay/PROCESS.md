# Process (small team)

A few people, so light review and no formal gates.

1. Work on a branch. Do not commit to main.
2. Open a pull request. Say what changed and why.
3. One teammate reviews before merge. Agent output gets the same review as human output.
4. Tests must pass before merge.
5. Merge, then add a line to `CHANGELOG.md` if users or other developers will care.

Keep it light. If review is slow, shrink the pull request before you drop the review.

See [ROLES.md](ROLES.md) for who does what.
