# skills

One amalgamated skill per principle (103), in `skills/<id>-<slug>/`, imported from the amalgamated-skills kit (see [IMPORT.md](../IMPORT.md)):

- `SKILL.md`: when to use, the producer's dos and don'ts together, steps, adversarial reviewer checks, how the sources compare, and the test slot.
- `SOURCES.md`: every source file, pinned to a commit, with its licence, and a "Further reading (link only)" section for sources that could not be copied or adapted.

Look up a skill by principle ID in [data/skill-principle-map.json](../data/skill-principle-map.json). A retired ID has no folder: resolve it to its survivor through `aliases` in [data/principles.json](../data/principles.json).
