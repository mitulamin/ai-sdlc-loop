# skills

One amalgamated skill per principle, in `skills/<id>-<slug>/SKILL.md`, with a `SOURCES.md` next to it (pinned source links and the dedupe summary).

There are 103 skills, one for each principle in [data/principles.json](../data/principles.json). Each `SKILL.md` carries the principle ID, any merged aliases, the category slug and a licence, and each `SOURCES.md` credits the source files it draws on. [data/skill-principle-map.json](../data/skill-principle-map.json) lists every skill with its phase and licence status, and `python scripts/check-skills.py` checks the folders against the principles. Per-source credits are in [CREDITS.md](../CREDITS.md).

Skills are drafted from sources, then hand-edited. A refresh only proposes changes to them. See [UPDATING.md](../UPDATING.md).
